
## Stack
- React
- React Router
- Tailwind CSS
- Vite

## Run
```bash
npm install
npm run dev
```

## Build
```bash
npm run build
```

## Implemented routes
- `/` Home
- `/collection` Collection + filters/sorting/search
- `/product/:id` Product details
- `/cart` Cart
- `/checkout` Delivery & payment
- `/orders` Orders
- `/about` About
- `/contact` Contact
- `/login` Login
- `/signup` Sign Up
